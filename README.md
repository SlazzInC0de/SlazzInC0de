### ▸ FLAGSHIP 01 &nbsp;·&nbsp; DATA ENGINEERING

<a href="https://github.com/SlazzInC0de/stratoflow"><img src="./assets/card-stratoflow.svg?v=1793039499" width="100%" alt="StratoFlow"/></a>

**One bad row should not kill a whole batch. StratoFlow makes sure it never does.**

- ▸ Sensor-type-aware **Pandera** schemas quarantine malformed rows (~10% of test data) while clean rows keep flowing
- ▸ Validated output lands as **Parquet** (61.7% smaller, measured) and is queried in place with **Synapse Serverless SQL**
- ▸ Every resource lives in **Terraform**, including imported manually-created ones, with CI/CD on GitHub Actions

### ▸ FLAGSHIP 02 &nbsp;·&nbsp; THEORY OF COMPUTATION

<a href="https://drawtomata.vercel.app"><img src="./assets/card-drawtomata.svg?v=1793039499" width="100%" alt="Drawtomata"/></a>

**Built because these conversions kept costing me marks in exams.** [Repo](https://github.com/SlazzInC0de/drawtomata) · [Live](https://drawtomata.vercel.app)

- ▸ Converts between **regular expressions, λ-NFA, NFA, DFA, minimal DFA, regular grammars, CFGs and NPDAs**
- ▸ Shows **every intermediate step**, the way you would write it on an answer sheet
- ▸ Every result is **checked for language equivalence** against its input before it is displayed

### ▸ FLAGSHIP 03 &nbsp;·&nbsp; SEMANTIC SEARCH

<a href="https://github.com/SlazzInC0de/imazinthecomicz"><img src="./assets/card-imazin.svg?v=1793039499" width="100%" alt="IMAZINTHECOMICS"/></a>
